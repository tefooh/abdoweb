# Artificial Intelligence Engineering and Data Portfolio

> From none to the universe

An interactive minimalist portfolio and digital showcase built for a client. Built with React, TypeScript, Vite, Tailwind CSS, GSAP, and Framer Motion.

Created by Mtarif and www.mtarif.com to a client.

## Overview

This portfolio showcases high precision digital products, AI automation systems, and engineering achievements. The architecture and visual presentation rely on simplicity, modern line art minimalism, and mathematical design balance.

## Features

* Interactive Projects Gallery:
  * Custom GSAP scene animations and responsive image slider effects
  * Staggered clip path motion transitions and detailed project modals
* Interactive Physics CTA:
  * Canvas driven interactive string mesh with dynamic wave physics
  * Hover triggered shockwave acceleration and multi layer staggered text animations
* Minimalist Branding and Design System:
  * Typography: McLaren display font paired with Merge One body typography
  * Color Palette: 70 percent monochrome base with controlled 30 percent gradient accents
  * Line Art Aesthetics: Monoline stroke icons, flat UI elements, and whitespace balance
* Ventures and Services Ecosystem:
  * Full breakdown of services including AI Automation Systems, Web and Mobile Engineering, UI and UX Design, and Brand Identity
  * Showcase of business ventures
* Fully Responsive and Accessible:
  * Smooth fluid layouts across desktop, tablet, and mobile devices

## Tech Stack

* Framework and Runtime: React, TypeScript
* Build Tool: Vite
* Styling: Tailwind CSS
* Animations and Motion: GSAP, Framer Motion
* Iconography: Lucide React

## Getting Started

### Prerequisites

* Node.js version 18 or higher
* npm version 9 or higher

### Installation

1. Clone the repository
2. Install dependencies with npm install

### Development

Run the development server with npm run dev. Open http://localhost:3000 in your browser.

### Production Build

Build the production application with npm run build.
