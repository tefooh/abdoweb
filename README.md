# Elfekky — AI Engineering & Data Portfolio

> **From none to the universe**

An interactive, minimalist portfolio and digital showcase for **Abdelrahman Elfekky** — Artificial Intelligence Engineer and Data Analyst. Built with React 19, TypeScript, Vite, Tailwind CSS v4, GSAP, and Framer Motion.

---

## 🌟 Overview

This portfolio showcases high-precision digital products, AI automation systems, and engineering achievements. The architecture and visual presentation adhere strictly to the **Elfekky Branding Identity** — built on simplicity, modern line-art minimalism, and mathematical design balance.

---

## ✨ Features

- **Interactive Projects Gallery**:
  - Custom GSAP scene animations and responsive image slider effects.
  - Staggered clip-path motion transitions and detailed project modals.
- **"Let's Rock" Physics CTA**:
  - Canvas-driven interactive string mesh with dynamic wave physics.
  - Hover-triggered shockwave acceleration and multi-layer staggered text animations.
- **Minimalist Branding & Design System**:
  - **Typography**: McLaren display font paired with Merge One body typography.
  - **Color Palette**: 70% monochrome base with controlled 30% gradient accents (`#DDFDFF` ➔ `#B7CEFF`).
  - **Line Art Aesthetics**: Monoline stroke icons, flat UI elements, and whitespace balance.
- **Ventures & Services Ecosystem**:
  - Full breakdown of services including AI Automation Systems, Web/Mobile Engineering, UI/UX Design, and Brand Identity.
  - Showcase of business ventures including Dietin (CTO & AI Backend Dev), Rokn Podcast, and Wagha INC.
- **Fully Responsive & Accessible**:
  - Smooth fluid layouts across desktop, tablet, and mobile devices.

## 🚀 Getting Started

### Prerequisites

- **Node.js**: `v18.0.0` or higher
- **npm**: `v9.0.0` or higher

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AbdelruhmanAshraf/elfekky-portfolio.git
   cd elfekky-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

Build the production application:
```bash
npm run build
```

Preview the production build locally:
```bash
npm run preview
```
